PyTorch Sinir Ağı Mimarileri ve Matematiksel Temeller

Gated Recurrent Unit (Cho vd., 2014)

1. Sıfırlama Kapısı (Reset Gate: $r_t$)
r_t = σ(W_r · x_t + U_r · h_{t-1} + b_r)

Geçmiş bilginin ne kadarının unutulacağını belirler.

2. Güncelleme Kapısı (Update Gate: $z_t$)
z_t = σ(W_z · x_t + U_z · h_{t-1} + b_z)

Unutma ve girdi kapılarının işlevini tek kapıda birleştirir.

3. Aday Gizli Durum ($\\tilde{h}_t$)
h̃_t = tanh(W · x_t + U · (r_t ⊙ h_{t-1}) + b)
4. Gizli Durum Güncellemesi ($h_t$)
h_t = (1 - z_t) ⊙ h_{t-1} + z_t ⊙ h̃_t
# PyTorch GRU Model Tanımı
class GRUModel(nn.Module):
    def __init__(self, input_dim=1, hidden_dim=32, num_layers=2, output_dim=1):
        super(GRUModel, self).__init__()
        self.gru = nn.GRU(
            input_size=input_dim,
            hidden_size=hidden_dim,
            num_layers=num_layers,
            batch_first=True
        )
        self.fc = nn.Linear(hidden_dim, output_dim)

    def forward(self, x):
        h0 = torch.zeros(2, x.size(0), 32, device=x.device)
        out, _ = self.gru(x, h0)
        return self.fc(out[:, -1, :])

Long Short-Term Memory (Hochreiter & Schmidhuber, 1997)

1. Unutma Kapısı (Forget Gate: $f_t$)
f_t = σ(W_f · x_t + U_f · h_{t-1} + b_f)
2. Girdi Kapısı ($i_t$) ve Aday Durum ($C̃_t$)
i_t = σ(W_i · x_t + U_i · h_{t-1} + b_i)
C̃_t = tanh(W_c · x_t + U_c · h_{t-1} + b_c)
3. Hücre Durumu Güncellemesi ($C_t$)
C_t = f_t ⊙ C_{t-1} + i_t ⊙ C̃_t
4. Çıktı Kapısı ($o_t$) ve Gizli Durum ($h_t$)
o_t = σ(W_o · x_t + U_o · h_{t-1} + b_o)
h_t = o_t ⊙ tanh(C_t)
# PyTorch LSTM Model Tanımı
class LSTMModel(nn.Module):
    def __init__(self, input_dim=1, hidden_dim=32, num_layers=2, output_dim=1):
        super(LSTMModel, self).__init__()
        self.lstm = nn.LSTM(
            input_size=input_dim,
            hidden_size=hidden_dim,
            num_layers=num_layers,
            batch_first=True
        )
        self.fc = nn.Linear(hidden_dim, output_dim)

    def forward(self, x):
        h0 = torch.zeros(2, x.size(0), 32, device=x.device)
        c0 = torch.zeros(2, x.size(0), 32, device=x.device)
        out, _ = self.lstm(x, (h0, c0))
        return self.fc(out[:, -1, :])

Eleştirel Bakış: Finansal Piyasalarda Yapay Zeka Yanılsamaları

Arvind Narayanan & Sayash Kapoor (Princeton Üniversitesi, "AI Snake Oil") yaklaşımı

Finansal makine öğrenimi modellemelerinde ve bu 1 aylık projede vurgulandığı gibi, geçmiş verilerdeki yüksek matematiksel başarı her zaman piyasada getiri garantisi anlamına gelmez:

1 Günlük Gecikme Yanılsaması

Zaman serisi modelleri genellikle $R^2 > 0.95$ gibi yüksek metrikleri kolayca yakalar çünkü aslında $\hat{y}_{t+1} \approx y_t$ kuralını öğrenirler. Tahmin çizgisi gerçek fiyatı 1 gün geriden takip ettiği için yön dönüşlerini önceden kestirmede yetersiz kalabilir.

Etkin Piyasa Hipotezi (EMH)

Hisse senedi fiyatları kamuya açık tüm bilgileri anlık olarak yansıtır. Gelecekteki ani sıçramalar beklenmedik haberler, bilanço açıklamaları ve makroekonomik olaylarla şekillenir; bu nedensellik tek başına geçmiş fiyat serisinde bulunmaz.

Durağanlık ve Getiri Modellemesi

Gerçek niceliksel (kantitatif) fonlar nominal fiyat seviyesi yerine logaritmik getirileri veya yön olasılıklarını (Yukarı / Aşağı) tahmin eder; haber analizi (NLP) ve işlem hacmi gibi çok boyutlu sinyalleri birleştirir.
